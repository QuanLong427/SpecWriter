# 方法怎样适配本书

先确定作者要交付的体验及已有文风。profile 的原则是讨论起点，sceneQuestions 和 reviewQuestions 用于寻找具体问题，pitfalls 是常见失效方式；它们都不自动成为本书约定。

选择需要的部分，说明与当前人物、世界规则、叙事视角和长期目标的关系。例如升级循环可以用于职业成长，但职业能力的边界与后果须按行业和现实程度重建；悬疑的信息边界可以服务言情秘密，但亲密关系推进不必变成竞技破案。

提供能落到本场的改法：改变欲求或阻力、让行动产生新的关系后果、调整信息何时揭露、让对白争取一个具体结果。保留作者想要的慢热、克制、群像或实验空间，不以模板覆盖已选风格。

作者明确选择具体做法后，区分“期待的体验”“可调整的手法”“必须遵守的约束”，再存 Specs 或 instruction。仅保存 craft 报告或选入 references 不等于全部原则已采用。审阅时引用正文与已采用约定，风格偏好通常作 suggestion/warning。

需要现实事实或当前读者趋势时另取可靠来源。内置经验没有热榜证据，也不能替代专业事实核对或真实长篇验证。
