# 从材料到原创机制

在报告 question 或 unknowns 标明作品、材料类型、已读章节或片段、缺失范围。摘录、简介、作者说明和完整正文支持的判断不同；本书已接纳正文可以分析，但分析报告仍不是新增事实源。

按本次目的选择观察，不必填写统一评分表：

- 读者承诺：材料让读者期待什么，通过哪个具体行动或问题建立？
- 冲突循环：欲求、阻力、选择、代价与后果怎样相连？成功或失败改变了什么？
- 场景：入场目标、争点、转折和离场变化在哪里，哪些细节承担了作用？
- 对白：人物想取得什么，怎样利用或暴露信息、关系和权力？
- 推进：如何让能力、关系、谜题或局势出现变化，如何保留以前的后果？
- 信息：人物和读者分别何时知道什么，误导和揭露有什么证据？

observations 保存材料支持的事实，interpretations 保存机制判断，directions 保存本书可选改法；无法从已读范围支持的内容列 unknowns。引文只保留分析所必需的短片段，避免把大段原作变成报告主体。

迁移先抽象关系，例如“新能力解决旧困难，同时暴露新代价”，再为本书建立完全不同的能力、目标、关系和因果。单换名字、重排原作标志性场面或复用辨识度高的设定组合都不算原创迁移。

比较作品时说明范围、类型和叙事目的的差异；慢热、群像、实验风格不自动服从同一节奏。方法只有适配理由，没有普遍有效保证。作者选择的体验优先。
